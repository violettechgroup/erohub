# EroHub

EroHub is a modern adult-media discovery platform focused on organized posts, creator profiles, responsive browsing and a clean magenta visual identity.

This public repository is intentionally presentation-only. It does not contain the application source, database, production configuration, private reports, user data or credentials.

## Project highlights

- Responsive post and profile browsing
- Media-aware cards and post detail pages
- Search, community discovery and taxonomy navigation
- SEO-friendly public routes and sitemap support
- Dark pink/magenta branding

The production application is maintained in a separate private repository.
